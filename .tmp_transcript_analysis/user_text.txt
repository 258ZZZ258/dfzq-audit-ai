## 3. 调研工作流（按序执行）

### 步骤 ① 现状盘点

通读并盘点以下模块的现有实现，产出**文件+函数级**的清单：

1. 摄取管线 S0–S5：每个阶段的入口、profile 分派机制（P-INT/P-EXT/P-QA/P-CASE 如何路由）、阶段间数据契约
2. S3 条款树构建与切块：clause_path_norm 归一化函数、chunk_id 生成、边界情况处理（超长条/超短条/"第X条之一"/表格块）
3. S4 元数据与版本链：字典对齐逻辑（dict_issuers / dict_biz_domains / dict_entity_types）、E402 未命中处置、版本链登记
4. 案例要素抽取（P-CASE 分支）：引用外规条款的 L1/L2 抽取实现、doc_no + clause_path_norm 归一化对齐、ref_unresolved 队列
5. 制度查询智能体检索侧：案例桥接通道（CP-007）如何消费 cases 表、相似案例精确反查（§6.5 对应实现）、entity_type 过滤链路
6. PG 模型：documents / doc_versions / chunks / cases / clause_references / clause_tags 及相关字典表的实际字段与约束
7. 质检（S2）：七项指标的实现方式与 profile 维度的启用配置

盘点中特别标注：**每一处隐含"文档需要自建解析/切块"假设的代码位置**，以及**每一处隐含"案例引用需 LLM 抽取"假设的代码位置**。

### 步骤 ② 影响分析

基于盘点结果产出：

**a. 字段映射草案**：源系统字段 → 现有 PG schema 的初步映射表，逐字段标注三态之一：直接映射 / 需归一化（给出规则草案）/ 无对应目标（潜在 add-only 新字段）。重点关注：
- 效力状态 → status 四值枚举的对齐
- 法律位阶（外规）与效力层级（内规）→ issuer_level 的归一化
- 适用对象 → entity_type[]（评估其对 CP-007 E2 富集工作的替代程度——潜在的工作量重大节省点）
- 违反法规子表.段落名称 → clause_path_norm（粒度是否一致：条 vs 款/项）
- "关联文件"页签若含废止/替代关系 → 对版本链人工录入的替代程度（另一个潜在节省点）
- 涉案人员子表 → 现有 cases 表无对应结构
- 问题汇总/案例描述 → 是否可替代 LLM 生成的 case_summary 块

**b. 失效/保留/缺口三分清单**：
- 失效：预切块语料上不再执行的环节（逐项标注是否有其他 profile 仍依赖）
- 保留：不受影响的环节
- 缺口：源数据引入后现有代码没有承接能力的点（如：源系统条款标识的解析、源导出文件的接入格式、页码缺失时的处置）

**c. 契约冲击评估**：逐条对照 §2 基准 B1–B8，标注绿（无冲击）/黄（需适配）/红（冲突，需决策）。

### 步骤 ③ 候选方案对比（只对比，不选择）

给出 **2–3 条改造路径**，每条包含：改动范围（触及哪些模块）、工作量粗估、风险点、对 B1–B8 的冲击、可回退性。至少覆盖以下两个方向（可补充第三条）：

- **方向 A：新增摄取 profile**（如 P-PRESEG）：源数据经适配器转为与 S3 产物同构的块流，从 S4 汇入现管线；现有管线完整保留为兜底
- **方向 B：独立直采通道**：源数据不走现管线，独立落库路径直写 chunks/cases，与现管线仅共享 PG/Milvus 写入层

对比维度中必须包含：**两条通道并存时的语料归属规则**（哪些语料走源系统、哪些仍走自建解析——监管问答是否在源系统内是关键未知项）。

### 步骤 ④ 未决问题清单

汇总所有阻塞决策的未知项，按 P0/P1 分级，逐项注明"向谁确认"（甲方对接会 / 源系统导出样例 / 内部决策）。至少应覆盖：

- 源系统条款块是否携带页码锚点（P0，决定 B3 是否受冲击）
- 源系统实际导出形态：格式 / 字段类型 / 主键 / 条款块唯一标识（P0）
- 切块粒度：条 vs 段落（"违反法规子表"用"段落名称"，与"按条切块"口径可能不一致）
- "关联文件""图谱"页签背后关系数据的可导出性
- 源系统语料覆盖范围（内规/外规/案例/监管问答各自是否全覆盖）
- 调研中新发现的其他未知项

### 步骤 ⑤ 交付与暂停

产出单一报告文件：`制度查询智能体_预切块数据源适配_调研报告_v0_1.md`，结构 = 现状盘点清单 + 影响分析（映射草案/三分清单/契约冲击）+ 候选方案对比 + 未决问题清单。

**报告交付后任务结束，等待讨论。不进行任何选型建议之外的实施动作，报告中的候选方案对比可给出倾向性分析但须明确标注"待讨论决策"。**
