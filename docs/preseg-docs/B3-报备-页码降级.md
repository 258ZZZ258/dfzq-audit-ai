# 报备:预切块语料通道引用口径变更(四级 → 三级)

> 收件:甲方项目对接人 · 发件:审计大模型系统开发组 · 2026-07-06
> 性质:验收口径变更**报备**(原口径:引用四级追溯"条款→文档→页码→版本"为验收硬约束)

## 变更内容

对**来自法规制度平台(预切块)通道**的语料,查询智能体引用追溯调整为**三级**:
**条款 → 文档 → 版本**,不含页码;引用展示处带显式标识。
自建解析通道(直接处理原始文件的语料)**四级引用不变**。

## 变更原因

1. 平台数据模型不含页码字段:语料在源系统已按"条"完成切块,块记录未携带原文页码锚点。
2. 页码在本系统中的作用是**防幻觉的锚点校验手段**(将答案引用回放到原文页面核验),
   而非用户查阅价值——用户按"某办法第X条"定位,不按页码定位。
3. 预切块语料**逐字来自贵方权威知识库**,出处即源系统记录本身(每条引用可追溯至平台
   源记录 ID),原有页面回放校验所防御的解析失真风险在此通道不存在。

## 配套保障(替代页码校验的质量手段)

- 逐块保留源系统记录标识与内容哈希,入库幂等、可对账(平台↔本系统逐条核对);
- 条款级精确定位不受影响:案例↔法规条款关联、条款级引用照常;
- 乱码/传输损坏检测照常拦截;语料批次报告含完整性对账。

## 请确认

若贵方对该通道语料仍要求页码,可行路径为"由平台提供原文文件,本系统重新解析补页码"
(独立后置工序,不影响现有进度),请一并示知。**如无异议,按本报备口径执行。**
